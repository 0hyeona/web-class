자바스크립트는 브라우저 자체를 객체로 이해하고 있으며, 최상위 객체를 window라고 부른다.

최상위 객체 window 아래에는 여러 객체들이 포함되어 있다.

  • document : 정보를 표현하는 문서 객체
  • location : 웹페이지의 위치 정보를 표현하는 객체
  • history : 이동했던 페이지들에 대한 정보를 관리하는 객체
  • console : 개발자 툴에 있는 콘솔 객체
  • navigator : 브라우저의 정보를 담고 있는 객체
